# DailyVox — Android Design Package

Design exploration and final cross-platform system for the DailyVox Android app, derived from the iOS product at getdailyvox.com.

## Contents

- `DESIGN-SPEC.md` — the full written spec: tokens, screens, platform rules, capability tiers, engineering mapping, and recommendations for iOS.
- `screenshots/` — PNG exports of every design turn:
  - `1a/1b/1c` — the three original directions (Material citizen / Brand-first / Night sky)
  - `2a/2b/2c` — the structural rethinks (Transcript-first / Sky-as-app / Instrument)
  - `3a` — the final merged system: Light + Dark themes, all screens, incl. iOS variants
  - `4a/4b` — system surfaces: widgets, Quick Settings, Live Update, assistants, Dynamic Island
  - `t0-brief` — assumptions, framework mapping, iOS-back notes
- `prototype/DailyVox Android.dc.html` — the live design canvas (open in a browser with internet access; loads Google Fonts).
- `DailyVox-Design-offline.html` — self-contained single-file version of the whole canvas, works offline.

## The short version

Recommended direction: **3a — one system, two themes.** Structure and motion from Material 3 Expressive, DailyVox's ink/cream/amber identity locked (no wallpaper theming), Light = cream paper, Dark = night sky, and the Twin's constellation screen stays dark in both ("the sky is always night").
