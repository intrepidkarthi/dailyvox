# Play Console — content rating questionnaire

Answers for the IARC questionnaire. Every one is "no" for the same structural
reason: the app has no network permission, so there is no user-generated content
to moderate, no messaging, no ads and no purchases.

| Question | Answer |
|---|---|
| Violence, sexuality, profanity, drugs, hate | **No** to all |
| Gambling or simulated gambling | **No** |
| Users can interact or exchange content | **No** — no network, no accounts |
| Users can share their location | **No** — no location permission |
| Shares personal information with third parties | **No** |
| Allows purchase of digital goods | **No** |
| Contains ads | **No** |

**Expected rating: Everyone / PEGI 3.**

## The one that needs a note

*"Does the app allow users to create and share content?"* — **No.**

The app can export a journal and open the system share sheet. That is the user
handing a file to another app they chose, on their own device. Nothing is
published, nothing is transmitted by DailyVox, and no other user can ever see
it — the app holds no network permission and there is no service behind it.

If a reviewer reads "share" as UGC, the honest expansion is above: no server, no
audience, no moderation surface.
