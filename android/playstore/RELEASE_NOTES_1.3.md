# Google Play — DailyVox 1.3 (versionCode 9)

The languages release: the app in German, Spanish, French, Italian and Brazilian
Portuguese as well as English, and the "share your sky as a Story" card. Hindi is
held back.

**1.2.1 never shipped.** Play's last release is 1.2 (versionCode 6), so these notes
also carry 1.2.1's fixes (`RELEASE_NOTES_1.2.1.md`): the speech-pack download instead
of an English transcript, quiet mood and trends where the app cannot read, and search
that no longer returns the whole journal.

> **The five translated notes are unreviewed machine drafts**, shipped by the owner's
> choice. They claim only what the build does in each language. Localized listings:
> `STORE_LISTING_l10n.md`.

## Release notes — en-US (English (United States)), max 500 characters

```
Now in German, Spanish, French, Italian and Brazilian Portuguese.
• Pick the language you speak, apart from the app's language
• Ask your Twin answers in the language you ask in
• Share your sky as a Story: how many nights, never your words
• No speech pack for your language? DailyVox offers the download, never an English transcript
• Mood, reflections and trends stay quiet outside English instead of guessing
• Search no longer lists your whole journal for a query it can't read
```

## Build

```
cd android && ./gradlew :app:bundleRelease
```

Sign the AAB, then upload to the internal testing track first, as in
`SUBMISSION_RUNBOOK.md`.

## Before you upload

1. **versionCode 9.** The release branch was at 8 when this was written; check
   `android/app/build.gradle.kts` before building.
2. **Engine.** DailyVoxTwin #38 and #39 merged. Without #39, Ask answers in English in
   every language and the second line of each note is false.
3. **Database upgrade.** Phones come from 1.2 (schema 4) and run `MIGRATION_4_5` then
   `MIGRATION_5_6` in one launch. Install 1.2 from Play on a test phone with entries,
   install this build over it, and check every entry, label, photo and recording.
4. **Device pass per language** (phone or per-app language): onboarding, an entry
   spoken in that language, the entry buttons (Edit / Ask fit), Search, Ask your Twin,
   the Story card, Settings › Language you speak. With only the English speech pack
   installed, choose another language: the app must offer the download, never write
   English.
5. **Store listing.** Add the five languages in Main store listing with
   `STORE_LISTING_l10n.md`, and upload each language's screenshots from
   `playstore/assets/screenshots/<lang>/` (being re-shot now).
6. **Data safety** — unchanged. No permission added; still no internet permission.
