## Notes for App Review (paste verbatim)

> DailyVox is a privacy-first voice diary. All AI runs on-device (Apple Speech/SpeechAnalyzer, NaturalLanguage, and — new in 1.7.0 — the Foundation Models framework); the app makes no network calls, requires no account, and functions fully offline. HealthKit (from 1.5.0) remains read-only, app-target only.
>
> NEW IN 1.7.0 — conversational "Ask Your Twin" using Apple's ON-DEVICE Foundation Models framework (iOS 26, Apple Intelligence devices only):
>
> • The user can type a free-text question; the answer is generated by the system's on-device language model, grounded in the user's own journal entries, and displays citation chips linking to the entries it drew from. A deterministic audit checks every answer before display; answers that fail fall back to the app's classic template responses.
>
> • No new permissions, no new entitlements, no network access: the Foundation Models framework is the same on-device system model that powers Apple Intelligence. Availability is checked via SystemLanguageModel; on devices without Apple Intelligence the feature is absent and the classic chat remains.
>
> • A Settings toggle ("Twin Brain") lets the user switch conversational answers off at any time.
>
> ALSO NEW — free-text questions on non-Apple-Intelligence devices answer via on-device semantic search (NLEmbedding): the app quotes the user's own closest entries verbatim, with citations. No generation, no model, fully offline.
>
> RESEARCH PILOT INVITATION: users who have journaled at least 15 entries over 3+ weeks see a single dismissible card in the Twin tab inviting them to an optional research study. The card only links out to getdailyvox.com/research; participation is an explicit, consent-first process conducted entirely outside the app (email). The app itself collects and transmits nothing; the App Store privacy label remains "Data Not Collected."
>
> HOW TO TEST: Twin tab → "Ask Your Twin". On any test device, typing a question returns quoted journal entries (record 2–3 short entries first). On an Apple Intelligence device, the same box returns conversational answers with citations. The pilot card will not appear on a fresh install (engagement-gated by design).
