# DailyVox Liquid Glass icon: Icon Composer layers

Generated by `make_layers.py`, which reuses `load_brand()` and `matte()` from `android/playstore/screenshot-src/make_icon.py`. Source: `ios/solyn/Assets.xcassets/AppIcon.appiconset/icon-ios-1024x1024.png`.

| File | What it is |
|---|---|
| `background.png` | 1024x1024, opaque RGB, full-bleed sage. It is the plane fitted to the original icon's sage. No rounded corners and no white margin. |
| `foreground-mic.png` | 1024x1024 RGBA. The mic only, at the exact pixel position and scale it has in the shipped icon. Bounding box 309,139 to 712,889, centre (510, 514). The baked cast shadow is removed because Liquid Glass adds its own. Edge pixels are un-blended from the sage, so they hold gold rather than a gold/green fringe. |
| `foreground-mic-mono.png` | 1024x1024 RGBA. A white single-colour silhouette of the same mic (no grille detail) for the Mono (Clear/Tinted) appearance. |
| `preview/` | Check renders only: original vs rebuilt, the mic on dark and light, mono, and a matte checkerboard. Not deliverables. |

Background gradient as numbers, if you would rather build it in Icon Composer (see step 3). The gradient runs diagonally from the top-left to the bottom-right:

## Icon Composer steps

Source for the Apple steps, read 2026-10-06: https://developer.apple.com/documentation/xcode/creating-your-app-icon-using-icon-composer

1. **Open Icon Composer.** In Xcode, choose **Xcode > Open Developer Tool > Icon Composer**. It ships with Xcode 26, and Xcode 26.3 is installed on this Mac. Choose File > Save and name the file **`AppIcon`**. The name matters: it is what Xcode matches against the target's App Icon field.
2. **Limit it to iOS.** Click the Document button (top right), choose **iOS Only** from the iOS/macOS pop-up and turn watchOS off.
3. **Background.** Apple's guidance is to *remove background colours and gradients from exported art and set them in Icon Composer*. Choose one:
   - **A (Apple-preferred):** click the icon filename in the sidebar. In the Style inspector, set Color to **All**, set Fill to **Gradient**, and use From `#89A27F` and To `#344D39`. Drag the gradient dots so it runs from the top-left to the bottom-right. Do not import `background.png` with this option.
   - **B (pixel-faithful):** drag `background.png` into the sidebar as the **bottom** layer, in its own group named `1-background`. Turn **Liquid Glass Effects off** for that layer, so it stays a flat matte.
4. **Mic.** Drag `foreground-mic.png` into the sidebar and put it in a group named `2-mic` **above** the background. Groups render bottom to top in the order they appear in the sidebar, and Apple's maximum is four groups. Do not move or scale it: it is already at the shipped icon's position. Select the `2-mic` group and set:
   - Mode: **Individual**
   - Specular: start with **Automatic**, and try **Inside** if the gold looks doubly lit. The PNG already has a painted highlight on the capsule.
   - Translucency: keep it **low** (around 0 to 20%). The mic is an opaque metal object, and high translucency washes the gold out.
   - Shadow: on. This replaces the baked shadow that the script removed.
   - Blur and Refraction: leave at their defaults or off. Refraction only shows on 27-generation rendering.
5. **Check every appearance.** Below the canvas, select iOS, then **Default**, **Dark** and **Mono**. Under Mono, click **Options** and look at Light and Dark, with **Tinted** off (that is Clear) and on (that is Tinted).
   - Dark: if the sage looks heavy, add a Dark-only variant of the background fill. In the Style inspector, use **Vary for Dark** on Fill and pick a deeper navy-to-sage pair, e.g. `#1B2A24` to `#101B2D`. Leave the mic gold.
   - Mono (Clear/Tinted): the photographic gold mic can go muddy when the system desaturates it. Two fixes:
     - Simplest: select the mic layer, set Color to the Mono appearance, and set **Fill: Solid white**. The layer then renders as a flat silhouette, and the system tints it.
     - Or: add `foreground-mic-mono.png` as a second layer in `2-mic`. Use the **Opacity** under Color, which varies by appearance, to set it to 0% in Default/Dark and 100% in Mono, and set the gold mic to 0% in Mono.
   - Use the toolbar's Background Image control to preview Clear over a real Home Screen wallpaper. Turn **Effects** off and on to compare with the flat icon.
6. **Turn the grid on** (toolbar: Grid, Light) and confirm the mic sits inside the icon grid at small preview sizes. Use "Select preview size" to check 60pt and 29pt.
7. **Save** `AppIcon.icon`.

## Adding it to Xcode

From the same Apple page, section "Add your Icon Composer file to an Xcode project":

1. Drag `AppIcon.icon` from Finder into the Project navigator, into the `solyn` app target's folder. Alternatively, use Add Files from the + button and tick the **solyn** target.
2. Open the target, then the **General** tab, then **App Icons and Launch Screen**. The **App Icon** field must equal the `.icon` filename without the extension. That gives `AppIcon`, which already matches `ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon` in `project.pbxproj`. Only one `.icon` may match that name.
3. Apple: *"The latest version of Xcode uses the Icon Composer file instead of an existing `AppIcon` asset catalog in your project."* and *"If your app supports previous releases ... Xcode automatically generates app icon images at build time for those releases from the Icon Composer file."*

**Decision you need to make (deployment target is iOS 17.0):**
- **Replace (Apple's default path):** add `AppIcon.icon`. Xcode then builds every icon, including those for iOS 17 and 18, from the `.icon`. You can delete `Assets.xcassets/AppIcon.appiconset`, or leave it, since Xcode ignores it when a `.icon` has the same name. The App Store 1024 icon is rendered from the `.icon` too.
- **Keep the exact flat icon on older iOS:** Apple says *"If you want your existing icon to appear in previous releases, continue to use asset catalogs to represent your app icon."* In that case, don't add the `.icon`, or accept the generated look-alike. I could not verify on Apple's page whether a `.icon` and an `.appiconset` with the same name can coexist so that each serves a different OS version. Treat that as unconfirmed, and test it with a build on an iOS 18 simulator before relying on it.
- Either way, build and run on a device or simulator, then look at the Home Screen in Light, Dark, Clear and Tinted. Also check the App Store icon in the archive's validation step.
